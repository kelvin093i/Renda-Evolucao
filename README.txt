RENDA & EVOLUÇÃO — ESTRUTURA INICIAL

Esta é uma primeira versão independente do Base44, feita para teste no Android.

ARQUIVOS
- index.html: entrada do aplicativo
- styles.css: visual
- app.js: telas e lógica
- manifest.json: informações para instalação como PWA
- README.txt: instruções

COMO TESTAR NO ANDROID
1. Extraia o ZIP.
2. Abra index.html no Chrome.
3. Escolha um objetivo.
4. Teste Início, Físico, Treino, Renda, Evolução e Estudos.
5. Os dados de XP/progresso ficam salvos no armazenamento do navegador.

OBSERVAÇÃO
Esta é uma estrutura inicial. Ela não contém ainda todo o conteúdo do aplicativo original, contas de usuário, sincronização online ou um APK nativo.
